 Hope Community Development Centre Website

Project Overview

The Hope Community Development Centre website is a responsive website developed to provide information about the organisation, its mission, vision, community programmes and activities. The website aims to connect community members, volunteers, donors, sponsors and other stakeholders with the organisation.

The website provides a simple and user-friendly platform where visitors can learn about the organisation, explore its projects and submit enquiries.

 Project Objectives

The main objectives of the website are to:

- Introduce the Hope Community Development Centre and its purpose.
- Share information about the organisation's mission and vision.
- Display community projects and development programmes.
- Provide contact information for interested visitors.
- Allow users to submit enquiries through an online form.
- Make information accessible on desktop, tablet and mobile devices.

## Website Pages

The website includes the following sections:

| Page | Description |
|---|---|
| Home | Introduces the organisation and highlights its work. |
| About Us | Provides information about the organisation, its mission and vision. |
| Projects | Displays the community projects and programmes. |
| Enquiry | Allows visitors to submit questions and enquiries. |
| Contact | Provides contact details and communication information. |

## Technologies Used

The website was developed using the following technologies:

- **HTML5:** Used to structure the website content.
- **CSS3:** Used to design the layout, colours and responsive interface.
- **JavaScript:** Used to add interactive features and functionality.
- **Visual Studio Code:** Used as the development environment.
- **Git and GitHub:** Used for version control and project hosting.

## Key Features

- Responsive design for desktop, tablet and mobile devices.
- Navigation menu for easy movement between website sections.
- Project search and filtering functionality.
- Interactive image gallery with a lightbox feature.
- Enquiry form with basic form validation.
- Contact form that prepares an email using the visitor's email application.
- Green, white and dark-green colour theme.
- Accessible and user-friendly layout.
- Search engine optimisation metadata.

## Installation and Setup

To run the website locally on your computer:

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Locate the `index.html` file.
5. Open the file in your browser.

Alternatively, use the following Git command:

```bash
git clone YOUR-GITHUB-REPOSITORY-LINK
```

Replace `YOUR-GITHUB-REPOSITORY-LINK` with the actual URL of your GitHub repository.

## Important Notes

The enquiry and contact forms currently use frontend functionality. They do not automatically save submissions to a database or send information to an organisation's server.

Before publishing the website for real organisational use, configure a backend service or form-processing solution. Update the contact email address and map information with the organisation's actual details.

Personal information submitted through future online forms should be handled responsibly and in accordance with applicable privacy requirements, including South Africa's Protection of Personal Information Act (POPIA).
